About this project

the # oriz-hash

A crypto/hash toolkit — SHA, HMAC, base64/hex, random, passwords, UUID — that runs entirely in your browser. This page describes the project; the tool itself lives at hash.oriz.in.

Open the live app → Source on GitHub llms.txt

What it is

oriz-hash ("the vault") is a single-page, 100% client-side toolkit for the everyday cryptographic primitives developers reach for. Every operation uses the browser's native Web Crypto API — there is no backend, no file upload, no account, and no tracking.

Key features

  • Hash — SHA-1, SHA-256, SHA-384, SHA-512 of text or any dropped file; hex or base64 output.
  • HMAC — keyed MAC over a message; key as text/hex/base64, any SHA algorithm.
  • Base64 / Hex — encode & decode both ways, incl. hex↔base64 and URL-safe base64.
  • Random bytes — cryptographically secure via crypto.getRandomValues; hex + base64.
  • Password generator — CSPRNG, tunable sets, no-look-alike option, live entropy strength meter.
  • UUID v4 — via crypto.randomUUID.

Tech

  • Client-only Astro (static) + React 19 islands + Tailwind v4.
  • Zero external crypto deps — native crypto.subtle / crypto.getRandomValues / crypto.randomUUID.
  • Optional AI polish via @chirag127/oz-ai (g4f, no key, multi-provider failover); core tools work if AI is down.
  • PWA-installable, offline-capable.
  • 100% in-browser — no upload, no signup. Free & open source (MIT).
